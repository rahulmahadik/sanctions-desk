Sanctions Desk

A review desk for sanctions-screening alerts. The desk recommends; a person decides. Nothing in it blocks an account, writes to a source system or contacts a customer.

This site is documentation only. It is static and makes no call to the desk, its API or any other service; to try the desk, run it in sample mode as the README describes.
