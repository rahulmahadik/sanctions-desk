A review desk for sanctions-screening alerts. The desk recommends; a person makes the final call (automatic closing is off by default). Nothing in it blocks an account, writes to a source system or contacts a customer.

Built on Zetaris, the only data path (one semantic layer over the sanctions lists, a bank database and a payments service); Meterless Nightshift, the primary path for every model call to local and cloud Nemotron models, where every answer carries a signed receipt (a local Ollama backup answers only if Nightshift fails, and has no receipt by design); and three Meterless engines, each in a working feature: H-MEM (memory of earlier decisions), the World Model (the ownership register the 50 percent rule is evaluated on) and Markovian (re-screening earlier decisions after a list change).

This site is documentation only. It is static and makes no call to the desk, its API or any other service; to try the desk, run it in sample mode as the README describes.

Which model does each step

  • Safety guard (inbound)Nemotron 3.5 Lightning · local
  • Free-text screenerNemotron 3.5 Lightning · local
  • DecisionNemotron 3 Ultra · cloud
  • CriticNemotron 3 Ultra · cloud
  • ChallengerNemotron 3 Ultra · cloud
  • Safety guard (outbound drafts)Nemotron 3.5 Lightning · local
  • Backup when Nightshift cannot answerOllama · backup, no receipt

The desk pins the mode it asks for, not the model that serves it. Details on the Nemotron scorecard.
